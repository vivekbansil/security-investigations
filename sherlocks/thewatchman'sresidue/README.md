# The Watchman's Residue – Windows DFIR & Remote Access Intrusion Investigation Lab

This investigation focused on a Windows workstation compromise involving remote management software abuse, credential harvesting, local data staging, exfiltration, and persistence. The objective was to reconstruct the attacker's activity by correlating evidence across network traffic, Windows logs, registry artifacts, file system metadata, and user activity artifacts.

This lab was completed in a controlled environment as part of hands-on digital forensics and incident response (DFIR) practice.
